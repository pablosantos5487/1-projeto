# 🍔 Lancheria do Pablo

Um site moderno e interativo desenvolvido para aumentar pedidos e engajamento dos clientes da Lancheria do Pablo.

## 🎯 Objetivo do Projeto

Criar uma presença digital profissional que:
- Aumente o número de pedidos pelo WhatsApp
- Melhore o engajamento com os clientes
- Destaque os produtos e promoções
- Facilite o contato e a localização

## 🚀 Tecnologias Utilizadas

- **HTML5** - Estrutura semântica e moderna

- **JavaScript** - Interatividade e animações suaves
- **Font Awesome** - Ícones profissionais

## 🚀 Como Personalizar

### 1. **Alterar número do WhatsApp**
Edite todas as ocorrências no HTML:
```html
<a href="https://wa.me/55SEUNUMEROAQUI" target="_blank">
```

### 2. **Mudar cores principais**
Edite o arquivo `css/style.css` e altere as variáveis CSS:
```css
:root {
    --first-color: #SUA_COR_PRIMARIA;
    --second-color: #SUA_COR_SECUNDARIA;
}
```

### 3. **Alterar imagens**
Substitua as URLs das imagens no HTML por suas próprias imagens:
```html
<img src="URL_DA_SUA_IMAGEM" alt="Descrição">
```

### 4. **Modificar textos**
Edite diretamente o conteúdo no arquivo `index.html`

### 5. **Adicionar/remover produtos**
Copie e cole novos cards no arquivo `index.html`
